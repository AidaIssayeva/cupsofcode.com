The Best Way To Get Started Learning About Android Development

Aida IssayevaJuly 15, 20241 min read
PART OF AN EXPERIMENTWriting in public · Ship 30 for 30↗

I love learning about Android Development.

Unfortunately, when I first got interested in Android Development, I had a hard time figuring out where to start.

So, if you are trying to learn more about Android Development, here’s the best way to get started:

  • Read This Blog: Developer Guides by Google will give you a lay of the land, and is a helpful way to get your bearings.

  • Take This Course: Android Kotlin Developer Nanodegree by Udacity is a must-read beginner resource for anyone interested in Android Development.

  • Listen To This Podcast: And if you really want to start going down the rabbit hole, listen to Fragmented Podcast by Donn Felker and Kaushik Gopal.

These 3 resources will exponentially accelerate your learning process.
